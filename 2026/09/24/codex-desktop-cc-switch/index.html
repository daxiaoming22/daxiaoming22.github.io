不翻墙也能用 Codex 桌面端：cc-switch + 国产 API 记录

发表于2026-09-24|更新于2026-09-24|教程
|浏览量:

1. 关于 Codex 如何绕开初始的强制登录

网上教程一大堆，大部分都要求你科学上网，但如果你没有怎么办？其实思路很简单：Codex（壳）+ 自己的 API（国产性价比）。

用 cc-switch 就行。安装这个 app 不难（微软商店就可以），然后用 cc-switch 切换成自己的 API，它可以把官方一开始强制的那一套全去掉，把 API 核心换成国产的。

2. 关于我目前的 agent 工具排行（仅供参考）

Claude CLI（无疑的神，插件生态异常成熟，加上 cc-switch 基本上所有的 API 都适用）> Hermes CLI/desktop（记忆的神，但感觉记忆太短了，希望这个 agent 进化时能把记忆库扩大一些）> Codex 桌面端（官方维护的插件。说白了，下桌面端的优势就在于它有官方自定义库，可以更好地自动化操作）> 豆包 / WorkBuddy（自定义程度较低，但办公应用等相对较成熟）> DeepSeek harness（版本不断迭代中，生态插件依旧不成熟，也没有官方维护的库，不推荐）

3. 关于 API

我一直用的两个：DeepSeek（一直是按用量的，但自从 ds 涨价，梁圣变成梁娘，账户余额也如落花流水，近 30 天 ¥140）和火山的 agent plan（首三个月 9.9 还是相当划算的，但我的三个月已经过期了，可怜）。后面打算订阅制了，小米的还没试过效果。同门说 ds 高峰期用小米 MiMo，谷底用 ds。
